# ลอยกระทงออนไลน์ เทศบาลตำบลคลองตำหรุ ๒๕๖๙

เว็บไซต์: **https://tanakrid1992-cpu.github.io/loykrathong/**

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (ฉาก, ป๊อบอัพประดิษฐ์กระทง, อัปโหลดรูป, แถบคำอธิษฐาน) |
| `bg.webp` | ฉากหลัง นาเกลือ กังหัน วัด |
| `krathong/k01–k20.webp` | กระทงแบบสำเร็จ 20 แบบ |
| `gas/Code.gs` | Backend เก็บข้อมูลลง Google Sheet + รูปลง Google Drive |

## ติดตั้งฐานข้อมูล (ครั้งเดียว ~5 นาที)
1. สร้าง Google Sheet ใหม่ (บัญชีเทศบาล) ตั้งชื่อ เช่น `ลอยกระทงออนไลน์2569`
2. เมนู **ส่วนขยาย > Apps Script** → ลบโค้ดเดิม วางโค้ดจาก `gas/Code.gs` → บันทึก
3. เลือกฟังก์ชัน `setup` → **เรียกใช้** → อนุญาตสิทธิ์ (จะสร้างชีต `krathong` และโฟลเดอร์รูปใน Drive)
4. **การทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
5. คัดลอก URL ที่ลงท้ายด้วย `/exec` ไปใส่ใน `index.html` บรรทัด `CONFIG` → `API_URL:"https://script.google.com/macros/s/.../exec"`

> ยังไม่ใส่ `API_URL` = โหมดสาธิต (ข้อมูลเก็บในเครื่องผู้ใช้เท่านั้น)

## ข้อมูลที่เก็บ (ชีต `krathong`)
`id, created_at, name, wish, img, base, flower, candle, deco, photo, approved, photo_file_id`
- รูปผู้ลอยย่อเป็น 240×240 px ก่อนส่ง เก็บในโฟลเดอร์ Drive `ลอยกระทงออนไลน์2569_รูปผู้ลอย`
- **ซ่อนข้อความ/รูปไม่เหมาะสม:** เอาเครื่องหมายถูกในคอลัมน์ `approved` ออก (มีผลภายใน ~15 วินาที)
- ผู้ใช้ต้องติ๊กยินยอม PDPA ก่อนลอยทุกครั้ง ควรลบข้อมูลหลังจบงานตามระยะเวลาที่ประกาศ
- แก้โค้ด `Code.gs` แล้วต้อง **จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่** ทุกครั้ง
